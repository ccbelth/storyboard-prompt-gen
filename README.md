# 分镜提示词生成器

给剧组用的分镜提示词拼装工具，单文件网页，双击就能用。思路是先锁资产，再一卡一镜：人物、道具、人物位置、场景全片只写一次，每一镜引用编号，导出 Markdown 直接交给生图模型。

## 用法

1. 浏览器打开 index.html，点“载入示例”可以看一份完整的分镜是什么样子
2. 资产区写场景、人物、道具、人物位置，生成 `{{Mixed N}}` 形式的占位编号，全片复用
3. 逐镜一卡一镜，写镜头号、景别、机位、动作、时长，需要时引用上面编号
4. 右侧实时出两种结果：Markdown 全文给人看，仅 AI 提示词给模型用。可以复制全文或导出 .md
5. 草稿自动存本机，换机器用备份 JSON 与恢复备份接着写
